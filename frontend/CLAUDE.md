# Frontend — UrbanLayer

## Stack

React + TypeScript + Vite + Tailwind v3. **One UI since Phase 10 (2026-11-14, decision Item 125): `src/app/`** (renamed from `src/ui-next/` 2026-11-15, Item 126; the `next` namespace, `nx-*` tokens, the `.ui-next` root class and `*Next*` file names keep their names; no `?ui=` flag, no old UI). Map: MapLibre GL over our own vector tiles (no Mapbox, no deck.gl; Satellite only as an opt-in layer, Item 128). State: React hooks. i18n: react-i18next with bundled JSON catalogs. Radix (Dialog, Tabs, DropdownMenu). Each page is its own lazy chunk (`app/pages.ts`); html2canvas/jspdf load only for a chat PDF export.

## Patterns

- **Per-message context**: each assistant message stores its own `context`, `plan`, `mapData`, `mapFetchedAt`. Citations survive multi-turn. Clicking a past user message loads that turn's data into the sidebar. **Per-message chips (2026-07-03)**: every completed assistant answer carries a `ContextChipStrip` (`Map · N / Data · N / Sources · N`, rendered via `MessageBubble`'s `footer` slot) that opens the panel/sheet on that tab **scoped to that turn** (reuses `handleMessageClick`; `"map"` falls back to the Data tab on desktop — `map` is a mobile-sheet-only SidebarView). Suppressed while streaming + on shared views. `countDataCategories` lives in `lib/contextSummary.ts`.
- **Citations**: `[N]` → `CitationPill` (§ section reference), `[data:X]` → `DataPill` (opens Data tab).
- **Tooltip**: `position: fixed` via `createPortal` to `document.body`, viewport-clamped with `useLayoutEffect`.
- **Routing**: `/` (landing for visitors, home when signed in; chat doors → `/chat`), `/chat` and `/c/:id` (chat), `/s/:shareToken` (a shared chat, read only), `/scorecard` (the Property Profile), `/discovery`, `/saved`, `/settings` and `/settings/:section`, `/pricing`, `/about`, `/privacy` (English only), `/admin` (admins only), `/explore` → `/discovery`, anything else → the 404 page.
- **Auth**: `AuthProvider` wraps the app in `main.tsx`. **No gate on `sendMessage`** — anonymous chat works up to the server's allowance (3 questions in total on a signed cookie, Item 120). Anonymous = in-memory only: `canPersist` (`!authRequired || isAuthenticated`) gates conversation creation, history load, and attachments (the conversation endpoints 401 without a session); workspace header shows a "Sign in to save your research" nudge, and a 429 renders the server detail + sign-in button (`rateLimited` from `useChat`, `ChatStreamError` from `api.ts`). `AuthModal` appears at identity moments only (nudge, share, purchase, 429). `UserMenu` in workspace header shows avatar + sign-out. Admin link only visible when `user.tier === "admin"`. In dev mode (no provider set up and `AUTH_DEV_LOGIN` off), auth is fully bypassed — no sign-in UI shown. With `AUTH_DEV_LOGIN=true` (localhost only) every provider without settings is a test stand-in, so signed-in screens can be reviewed (Item 121).
- **401-interceptor**: `authFetch()` in `api.ts` intercepts 401 responses, attempts `POST /api/auth/refresh` via raw `fetch` (not `authFetch` to avoid recursion), coalesces concurrent refreshes with a module-level `_refreshPromise`, re-reads CSRF cookie after refresh, retries original request once.
- **History stripping**: `useChat.ts` sends only `{role, content}` in chat POST history (strips `context`/`plan`/`mapData` blobs) to avoid HTTP 413 from nginx's `client_max_body_size`.
- **Stream close detection**: `useChat.ts` tracks `receivedDone` flag — if the SSE stream ends without a `done` event and wasn't user-aborted, shows "Connection lost — please try again."
- **i18n**: `react-i18next` with 8 namespaces (`common`, `chat`, `sidebar`, `landing`, `map`, `data`, `pages`, `next` = the site's own strings; the others hold strings the shared libraries still use). Languages: English (default) + Spanish. **Spanish means Mexican Spanish (es-MX)** (Jack, 2026-10-29): Mexican vocabulary, not Spain's (*agregar* not *añadir*, *terreno* not *suelo*, no *vosotros*/*ordenador*/*coger*). **Register is formal *usted* everywhere** (Jack, 2026-10-29): a new Spanish string uses *usted* verbs and *su*, never *tú*/*tu*. Dates and numbers already format as `es-MX` (`LOCALE_MAP`); the chat synthesizer names the dialect and the register in `LANGUAGE_NAMES["es"]` (`backend/synthesizer.py`). Bundled JSON resources in `src/locales/{en,es}/`. Language persisted in localStorage as `urbanlayer-language`. The language is chosen in the side panel and Settings → Preferences. Backend synthesizer responds in target language via `LANGUAGE_INSTRUCTION` prompt append — English path is +0ms latency. The **$25 Feasibility Report** is also localized (deterministic, no LLM): `fetchReport`/`createReportCheckoutSession` pass `language`; the backend renders via `backend/report_i18n.py` (see backend CLAUDE.md). Adding a new language: create `src/locales/{code}/` with the JSON files + add it to the side panel's and Settings' choices + add entry to `LANGUAGE_NAMES` (`backend/synthesizer.py`) **and `MESSAGES` (`backend/report_i18n.py`)**. Non-React code (mapColors.ts, mapTooltip.ts, termDefinitions.ts) uses `i18n.t()` directly; scorecard/regulatory enum + zoning-qualifier strings go through `format.ts` helpers (`translateFloodSubtype`, `localizeZoningValue`). **Guards:** `src/i18n.parity.test.ts` asserts en/es key-set + interpolation-placeholder parity across all 7 namespaces (catches the drift class that caused the "3 of 5"/"3 of 3 zones" bug); backend `test_report_i18n.py` does the same for the report catalog. **Not localized by design:** Admin, About, Privacy.
- **Pipeline timing**: The `done` SSE event includes a `timings` dict (`PhaseTimings` in `types.ts`) with `conv_synth`, `router`, `retrieval`, `first_token`, `total` (all in ms). Logged to console via `[perf] pipeline timings (ms):` in `useChat.ts`.

## Docker / Nginx

- **Dockerfile**: multi-stage (node build → nginx serve). `NGINX_CONF` build arg selects config (defaults to `nginx.conf` for dev).
- **`nginx.conf`**: dev config — port 80 only, proxies `/api/`, `/chat`, `/health`, `/autocomplete`, `/section/` to `backend:8001`. SPA fallback for all other routes.
- **Both configs (2026-11-14 swap lessons):** `/assets/` names `.mjs` as `application/javascript` (MapLibre's worker is a module; nginx's `mime.types` lacks `.mjs`, and an `octet-stream` worker meant no maps), and `location /chat` sends GET/HEAD to `index.html` (the page) and only the POST to the backend (else a reload of `/chat` is a 405). `npm run sweep:live` catches both.
- **`nginx.prod.conf`**: production config — HTTP→HTTPS redirect on port 80, SSL termination on port 443 (Cloudflare Origin Certificate), security headers (HSTS, CSP, X-Frame-Options DENY), gzip compression. Same proxy locations as dev plus `X-Forwarded-Proto`. `client_max_body_size 16m` on `/api/` and `/chat` location blocks.
- **CSP domains**: `script-src` allows `static.cloudflareinsights.com`; `style-src` allows `fonts.googleapis.com`; `font-src` allows `fonts.gstatic.com`; `img-src` allows `lh3.googleusercontent.com` (Google avatars); `connect-src` allows `*.ingest.de.sentry.io` (Sentry) + `*.clarity.ms`/`c.bing.com` (Clarity); `script-src` allows `www.clarity.ms` + `scripts.clarity.ms` and the sha256 of the inline theme script in `index.html` (recompute if that script changes). The CSP is defined once in a `map $csp` at the top of `nginx.prod.conf` and referenced from both header sites. **Client IP:** `real_ip` trusts `CF-Connecting-IP` only from Cloudflare ranges; proxy blocks overwrite `X-Real-IP`/`X-Forwarded-For` with `$remote_addr` (never append) — `backend/rate_limit.client_ip` reads only `X-Real-IP`, only from a private peer.
- **Production deploy**: `docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d` — the override adds port 443, SSL cert volume mount, and selects `nginx.prod.conf`.

  (Galaxy S24 360w / iPhone SE 375w / Pixel 3 393w / iPhone 15 393w / iPhone 15 Pro Max 430w;
  iPhones on WebKit, Androids on Chromium). Failures name the exact offending element; also flags
  fixed-position chrome extending past the viewport (clips invisibly — scrollWidth can't see it).
  Screenshots + JSON in `test-results/mobile-audit/`; new routes = one entry in the spec's `PAGES`.
  **Lessons baked in:** decorative `absolute -inset-*` bleeds widen the page — fix with
  `overflow-x-clip` on the *section root* (clip ≠ hidden: no scroll container, sticky survives),

  read as dead when they're fine — the spec scrolls in steps for this reason).
